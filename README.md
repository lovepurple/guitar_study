# 🎸 guitar_study — 成人零基础电吉他夜间静音自学指南

一套专为 **零乐器基础、下班晚、每日仅 15–30 分钟碎片时间、需戴耳机静音练习、喜欢摇滚/电子乐/低音律动** 的成人学习者打造的开源自学仓库（可直接复用）。

## 适合谁？
- **年龄/基础**：30+ 上班族、完全零基础（不懂五线谱/没学过任何乐器）。
- **时间/环境**：工作日每晚 15–30 分钟 + 周末 1 小时；夜间戴耳机静音练习，不扰民。
- **预算定位**：1500 元 RMB 以内收二手电吉他 + 便携耳放/入门综合效果器。
- **风格偏好**：摇滚（Rock）、电子乐（Electronic）、低音律动（Bassline），拒绝纯枯燥爬格子。

## 快速开始
1. 先看 [`docs/01-gear-and-silent-setup.md`](./docs/01-gear-and-silent-setup.md)，买齐“二手琴 + 有线耳放/效果器 + 落地琴架”。
2. 在收到琴之前，用浏览器打开 `code_artifact.html` 听听强力和弦与五声音阶的声音，提前熟悉指板。
3. 拿到琴后按 [`docs/02-roadmap-6-months.md`](./docs/02-roadmap-6-months.md) 从 Phase 0 开始，每天花 1 分钟在 `practice-log/` 打卡。
