# 01. 1500元内二手选琴与夜间耳机静音方案

> 原则：**手感和音准是新手能不能坚持下去的第一道门槛**。宁可买成色一般的正规大厂入门款，也绝对不买全新 500 元的「网红炫酷烧火棍」。

---

## 一、1500元内二手电吉他怎么选？

你喜欢 **摇滚 + 电子乐 + 低音律动**，最稳妥的拾音器配置是 **HSS（单-单-双）** 或 **HH（双-双）**：
- 琴桥位置有 **双线圈拾音器（Humbucker）**：抗干扰、失真厚实有力，弹摇滚 Riff 冲劲足、底噪小。
- 琴颈有单线圈或切单功能：能兼顾清音、放克/电子感律动。

### 1. 推荐型号（闲鱼 / 线下二手常见价位）

### 2. 新手买二手「绝对避坑」清单

1. **❌ 避开「双摇琴桥」（Floyd Rose 锁弦颤音系统）**：换弦、调音极度折磨新手，还会因为二手金属件老化导致跑音，**务必选固定琴桥（Hardtail）或普通单摇（6点/2点小摇）**。
2. **❌ 避开「杂牌炫酷异形琴 / 套装琴」**：全新四五百带音箱的套装几乎都是「烧火棍」，弦距高到按不动、品丝割手、十二品音准飞掉，直接劝退。
3. **❌ 避开「重度改装 / 断颈修复 / 琴颈扭曲」**：卖家写“自己换过拾音器/磨过品丝/修过琴头”的，新手无法判断手艺好坏，直接跳过。

## 二、二手验琴 6 步清单（面交或收快递录像）

1. **看琴颈是否笔直**：从琴头顺着指板边缘往琴桥看，应呈极轻微的凹弧或接近笔直；**如果左右扭曲（麻花颈）直接退货**。
2. **测弦距（Action）**：在 12 品位置，6 弦底部到品丝顶部的距离理想在 **1.8mm – 2.2mm** 左右；太高按着累，太低可能打品。
3. **逐品按弦听打品**：1~6 弦从 1 品到 15 品逐个按响，不应该出现明显的「滋啦」金属撞击杂音（轻微贴近打品可调琴颈钢筋，大面积打品可能是品丝不平）。
4. **查品丝边缘**：手指顺着琴颈上下两侧快速轻划，**不应有割手/扎手的金属毛刺**。
5. **测旋钮与电路**：插上耳机设备，分别拨动 5 档/3 档切换开关、拧动音量（Volume）和音色（Tone）旋钮，**转动时不应该有剧烈的“喀啦喀啦”接触不良断音**。
6. **看八度音准**：用调音表调准空弦后，轻按第 12 品再弹响，调音表指针也应该基本指在正中（偏太多可在琴桥弦鞍微调，但前提是琴本身结构正常）。

## 三、夜间耳机静音方案（不扰民 + 契合摇滚/电子）

**⚠️ 关键警告：不要用蓝牙耳机练电吉他！**
蓝牙音频编码有 100~300ms 延迟，你拨弦后耳机过零点几秒才响，节奏感会彻底毁掉。**必须用 3.5mm 或 6.35mm 有线耳机**（普通几十到两百块的有线监听耳机或手机有线耳机转接头即可，日后可升级如 Sony MDR-7506 / 铁三角 M40x 等）。

电吉他直接插耳机是没声音的（需要前置放大和箱体模拟），你有两种最适合下班晚练的方案：

### 方案 A：便携口袋耳放（最省事、随时拿起就练）— 预算 350–700 元
- **代表型号**：**NUX Mighty Plug Pro（MP-3）**、**Fender Mustang Micro**、**Mooer Prime P1 / P2**
- **为什么适合你**：
  - 直接插在吉他接口上，再插有线耳机，**零连线缠绕**，下班累了往沙发一坐就能练 15 分钟。
  - 自带失真、过载、延迟、混响等几十种效果器音色，**手机蓝牙连它放伴奏/鼓机**（注意：伴奏走蓝牙输入进耳放没关系，吉他信号进耳朵是纯有线零延迟！）。
  - 还能当 USB 声卡连电脑，以后想玩电子乐 DAW（如 Ableton Live / FL Studio / GarageBand）也能直接录音。

### 方案 B：入门综合效果器（可脚踩切音色、带鼓机+Loop）— 预算 500–900 元
- **代表型号**：**NUX MG-300**、**Valeton GP-100 / GP-200LT**
- **为什么适合你**：
  - 自带 **鼓机（Drum Machine）和 60 秒循环录音（Looper）**！你可以先用低音感音色录一段简单的 Bassline 循环，再切失真音色在上面弹摇滚 Riff，**完全贴合你喜欢电子+低音的审美**。
  - 有耳机输出口 + AUX 伴奏口 + USB 声卡功能。

> **总结建议**：如果空间小、追求「拿起来 10 秒就能练」，选 **NUX Mighty Plug Pro / Mooer Prime P1**；如果桌边能放得下、想玩自带鼓机 + Looper，选 **Valeton GP-100 / NUX MG-300**。

## 四、必备小配件清单（约 150–250 元）

1. **有线耳机**：手头任意有线耳机（带 3.5mm 插头）先用着，注意耳放/效果器接口是 3.5mm 还是需要 **3.5mm 转 6.35mm 转接头**（几块钱）。
2. **拨片（Pick）**：买一盒混合厚度（**0.73mm 和 0.88mm** 最适合新手兼顾扫弦与单音 Riff，建议 Dunlop Tortex 或 Jazz III XL 试试手感）。
3. **调音工具**：耳放/综合效果器通常自带调音表；手机也可以装免费 App（如 **GuitarTuna** 或 **Fender Tune**）。
4. **琴弦（备用）**：新手推荐 **009–042（09-42）** 规格（如 Elixir 12002 防锈弦约 70-90 元一套，防手汗不生锈，省得老换弦；或者 D'Addario EXL120 约 35 元）。买完二手琴后，强烈建议换一套新弦并让琴行或自己顺便擦拭指板。
5. **吉他背带 + 落地支架**：**一定要买个几十块的落地琴架**，把琴放在随手能拿到的地方！琴装在包里拉上拉链 = 吃灰率翻倍；放在架子上 = 每天下班顺手就能抱起来练 15 分钟。
6. **短连接线（仅方案 B 需要）**：3 米左右的 6.35mm 乐器线（约 40–60 元）。
